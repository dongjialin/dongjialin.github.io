推荐工作流

  1. 创建文章：hexo new "文章标题"
  2. 编辑文章：编辑 source/_posts/ 下的 Markdown 文件
  3. 本地预览：hexo s，在浏览器打开 http://localhost:4000 查看效果
  4. 发布上线：hexo clean && hexo g -d

记住这些命令，Hexo 博客管理就变得非常简单了！
